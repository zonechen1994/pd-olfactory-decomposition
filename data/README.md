# Source data (not redistributed)

All source data come from the Parkinson's Progression Markers Initiative (PPMI, RRID:SCR_006431) and are available on application at www.ppmi-info.org/access-data-specimens/download-data. The PPMI Data Use Agreement does not permit redistribution of the data, including derived participant-level values, so none are included in this repository. Place the files below under one directory, keeping the `molecular/` subfolder, and point the environment variable `PPMI_DATA_DIR` at it (default: the repository root).

| File (relative to `PPMI_DATA_DIR`) | Content | Size (MB) | MD5 of the copy used | Needed by |
|---|---|---|---|---|
| `PPMI_Curated_Data_Cut_Public_20260223.xlsx` | Curated Data Cut, public release of 23 February 2026, sheet `20260105` (visit-level table) and its `Data dictionary` sheet | 12.3 | `b02f60b863c2a117335c7f35ce1e0911` | every script |
| `Xing_Core_Lab_-_Quant_SBR_18Mar2026.csv` | Imaging core laboratory DaTscan specific binding ratios, 18 March 2026 | 2.7 | `12c8a82f2b4ac79132180650566a917c` | every script |
| `molecular/Current_Biospecimen_Analysis_Results_24Mar2026.csv` | Biospecimen analysis results, 24 March 2026 (CSF tau and amyloid, neurofilament light chain, seed amplification) | 177.1 | `0cd03bd368d166026d11520afa20a098` | `04_residual.py` |
| `molecular/PPMI_Project_282_NULISAseq_CNSDiseasePanel_NPQCounts_20260120.xlsx` | NULISA CNS disease panel, Project 282, sheet `NPQ Values` (cross-platform check of the pTau181 signal) | 30.8 | `0cbd974b32cb4957738c61a0a5d7d4c9` | `04_residual.py` |

The first two files are sufficient for the model, the survival analyses, the discrimination results and the baseline table (scripts 01, 02, 03, 05, 06, 07). The two `molecular/` files are needed only for `04_residual.py`.

## Derived files that are regenerated, not distributed

`results/repro/all_mismatch_scores.csv` (participant-level OIS and OMI for 3,895 participants) and everything under `results/intermediate/` are participant-level and are therefore not included. Every other file under `results/repro/` is an aggregate table or the numerical ledger and is included as generated by the scripts.
