# JTM reproducibility guide, 24 September 2026

Base code: zonechen1994/pd-olfactory-decomposition commit
`2cd66e497973aa422e361c3de587df6dc0bf14b6`. The base scripts are preserved so the
original outputs and the audit changes can be inspected separately. The corrected
JTM results are generated by `audit/JTM_20260924/audit_analysis.py`.

Corrections are a single Coxnet comparator implementation (alpha 0.1, l1 ratio
0.05, fold-specific scaling), two-sided head-to-head comparisons, genuine
landmark risk sets and reset times, matched complete-case exclusions when
retaining baseline PD, and one interval source for each repeated C-index.
Hyperparameters were not tuned to the observed comparison results.

## Reproduction

Use Python 3.12 and install `requirements.txt` (which includes `openpyxl`). See the original
README and `data/README.md` for licensed PPMI inputs. Set `PPMI_DATA_DIR` to the
directory containing those inputs with their original relative filenames (including
the `molecular/` directory). This repository contains no PPMI participant data or
intermediate participant frames. Run `python RUN_JTM.py` from the repository root.
This first runs the base analyses,
then applies the audited analysis and regenerates affected figures and source data.
The full base analysis can take tens of minutes.

**Use the corrected outputs under `audit/JTM_20260924/results/repro/` for the JTM
submission.** The root `results/repro/` is the uncorrected base run, retained for
comparison. Corrected figures are under `audit/JTM_20260924/figures/` and figure
source data in `audit/JTM_20260924/Source_Data.xlsx`.

`audited_aggregate_outputs/` contains the numerical audit from the server run,
including raw bootstrap tail counts, valid-resample counts, cohort flow and
fold-completion checks. These are aggregate data. The manifest records the input
checksums and exact package versions used. Every audited paired C-index comparison
had 1,000 usable resamples. The reported two-sided bootstrap tail-area P is
`max(2*min(count(delta<=0),count(delta>=0))/B_valid, 1/1000)`.
The original section 33 and 36 RNG streams are retained. New head-to-head and
landmark bootstrap runs use NumPy default_rng(42); their Monte Carlo samples
therefore differ from the legacy RandomState runs. All intervals condition on
the fitted scores and do not account for re-fitting uncertainty.

The audit independently re-fit the frozen ridge model, reconstructed survival
times and sample flow, reproduced the six primary comparisons and section 36
intervals exactly, and checked KM splits and IPCW AUC point estimates. It also
recomputed ICC, CSF regressions and genotype contrasts. Other exploratory analyses
remain as generated by the base scripts. The submitted DOCX files preserve the
authors' reference fields and are not regenerated by this numerical package.

The corrected analysis scripts and aggregate audit outputs are included in this
repository. `Source_Data.xlsx` matches the submitted Supplementary Material 2.
